## 🧭 What I Learned (Retrospective)

> *"Learning AI Fluency does not guarantee you an immediate job, nor does it guarantee you will understand how to build an application from scratch to mastery instantly. AI Fluency teaches you that work must be done iteratively, and that you need to create a design/ADR before building a real-world application. Don't expect an application to be built with just one 'magic prompt'."*  
> — **Ahmad Bayu Samudera** *(Message to My Week 1 Self)*

Here are the **3 biggest takeaways** from my 8-week journey:

1. **Plan before coding:** Writing down a clear plan and decision log (ADR) helps the AI stay on track and stops it from guessing or writing messy code.
2. **Test like a real user:** AI only knows if code runs without errors. It doesn't know if a button is awkward to click or if text is hard to read. You always have to test and polish the experience yourself.
3. **Keep things safe & tidy:** Never trust raw AI output blindly. Always add error handling, test edge cases, and keep sensitive keys secure.

## 🛠️ How to Run This Locally

Want to try the interactive dashboard on your computer? It only takes 2 steps:

```bash
# 1. Download or clone this folder
git clone https://github.com/AhmadBayu1412/flyrank-ai-capstone.git
cd flyrank-ai-capstone

# 2. Open index.html in your browser, or start a simple local server:
# Using Python:
python -m http.server 3000

# Or using Node.js:
npx serve .
```

Then visit `http://localhost:3000` or open [**flyrank-ai-capstone.netlify.app**](https://flyrank-ai-capstone.netlify.app/)!
